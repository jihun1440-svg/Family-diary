# 우리 가족 기록장

가족이 함께 할 일과 공부를 체크하고, 칭찬 도장과 저금통 기록을 쌓는 모바일 중심 웹앱입니다.
휴대폰 세로 화면에 맞춰 만들었고, 태블릿·PC에서도 가운데 정렬로 자연스럽게 보입니다.

## 파일 구성

| 파일 | 설명 |
| --- | --- |
| `index.html` | 화면의 뼈대 (이 파일만 열면 앱이 실행됩니다) |
| `style.css` | 크림색 배경과 파스텔 카드 디자인 |
| `app.js` | 기록 저장, 도장 계산, 타이머, 날씨, 동기화 등 모든 동작 |
| `preview/` | 화면 미리보기 이미지 |

외부 라이브러리나 빌드 도구를 쓰지 않습니다. 세 파일을 같은 폴더에 두고 `index.html`을 열면 바로 동작합니다.

## 처음 시작하기

처음 열면 `예준 · 엄마 · 아빠` 구성원과 예시 기록이 들어 있습니다. 화면 위의 **예시 데이터** 배지를 누르면
`예시로 되돌리기` / `기록 비우고 시작`을 고를 수 있습니다. 설정(⚙️)에서도 같은 메뉴를 쓸 수 있습니다.

기록은 이 기기의 브라우저 저장소(localStorage)에 자동으로 저장됩니다. 새로고침하거나 앱을 닫아도 그대로 남습니다.

## 휴대폰에서 열기

1. **같은 Wi-Fi에서 잠깐 열어 보기**
   컴퓨터에서 이 폴더로 이동한 뒤 `python3 -m http.server 8000`을 실행하고,
   휴대폰 브라우저에서 `http://컴퓨터IP:8000` 주소를 엽니다.
   (예: `http://192.168.0.12:8000`)
2. **인터넷에 올려서 가족과 함께 쓰기**
   GitHub Pages, Netlify, Vercel 같은 무료 정적 호스팅에 이 세 파일을 올리면 주소가 생깁니다.
   주소가 https이면 날씨 연결과 휴대폰의 홈 화면 추가가 모두 정상적으로 동작합니다.

> 파일을 그대로 열면(`file://`) 브라우저 보안 규칙 때문에 날씨 API를 부를 수 없어 화면에
> `날씨 연결 필요`만 보입니다. 이때도 나머지 기능은 모두 정상 동작합니다.

## 들어 있는 기능

**기본 기록**
- 오늘 날짜·요일(한국 시간 기준), 인사말, 가족 프로필 카드(오늘 완료 수, 누적 별, 저금통 금액)
- 구성원 추가·이름 변경·아이콘·색상 변경·삭제
- 구성원별 할 일 추가·수정·삭제, 체크와 취소(완료는 흐리게 + 취소선), `2/3개 완료` 표시
- `매일 반복` / `오늘만` 구분. 날짜가 바뀌면 반복 항목만 새로 올라오고 지난 기록은 그대로 남습니다.

**공부와 보상**
- 공부 항목·분량·담당자·보상 금액 입력, `매일 고정` 설정
- 전체 및 구성원별 진행 막대(`9 / 11 완료`)
- 완료하면 보상이 저금통에 한 번만 쌓이고, 취소하면 그 내역이 함께 사라집니다(중복 적립 방지)
- 보호자가 내역을 직접 추가·수정·삭제할 수 있습니다. 실제 결제나 송금은 없습니다.

**도장판**
- 도장 대상과 기준 개수를 설정에서 바꿀 수 있습니다. (기본: 1개 이상 완료)
- 이번 주 월~일 현황, 이번 달 도장 수, 연속 기록일, 달력 보기
- 완료를 모두 취소하면 도장과 연속 기록이 실제 기록에 맞춰 바로 다시 계산됩니다.

**가족 미션**
- 오늘의 미션 하나 표시, `다 같이 했어요` / `다른 미션 뽑기`
- 완료한 날짜와 누적 횟수(`함께 N번`), 미션 추가·수정·삭제

**타이머**
- `남은 시간`(카운트다운) / `재는 시간`(스톱워치)
- 10·20·30분 빠른 선택과 직접 입력, 시작·일시정지·이어하기·초기화
- 시간이 끝나면 화면 알림, 알림음(설정에서 끌 수 있음), 진동

**날씨**
- Open-Meteo 무료 API로 현재 기온·최저/최고·미세먼지·초미세먼지를 받아옵니다. (키 필요 없음)
- 지역은 설정에서 바꿀 수 있고, 기본값은 `고양시 일산동구`입니다.
- 연결에 실패하면 숫자를 지어내지 않고 `날씨 연결 필요`로 표시합니다.

**보관과 공유**
- 4자리 가족 PIN 잠금(선택)
- JSON 내보내기 / 불러오기
- 링크와 공유 코드로 지금 기록 그대로 보내기
- 여러 기기 실시간 동기화(아래 설정 필요)

## 여러 기기에서 함께 쓰기 (외부 설정 필요)

기본값은 `쓰지 않음`이며, 이때는 이 기기에만 저장됩니다. 아래 중 하나를 설정하면
가족 휴대폰끼리 몇 초 안에 같은 기록을 주고받습니다. 설정 화면의 `📡 여러 기기 동기화`에서 입력합니다.

### 1) Firebase Realtime Database

1. [Firebase 콘솔](https://console.firebase.google.com)에서 프로젝트를 만들고 **Realtime Database**를 만듭니다.
2. 규칙(Rules)을 아래처럼 두면 가족 방에 읽기·쓰기가 가능합니다.
   ```json
   { "rules": { ".read": true, ".write": true } }
   ```
   누구나 접근할 수 있는 규칙이므로, 방 이름을 `cho-family-8f3a91`처럼 추측하기 어렵게 정하세요.
   더 안전하게 쓰려면 Firebase 인증을 붙이고 규칙에 사용자 조건을 걸어야 합니다.
3. 데이터베이스 주소(`https://프로젝트-default-rtdb.firebaseio.com`)를 복사합니다.
4. 앱 설정에서 방식을 `Firebase Realtime Database`, 주소에 붙여 넣은 주소, 가족 방 이름을 입력하고 **연결하기**를 누릅니다.

### 2) Supabase REST

1. [Supabase](https://supabase.com)에서 프로젝트를 만듭니다.
2. SQL Editor에서 아래를 실행해 표를 만듭니다.
   ```sql
   create table if not exists family_records (
     room text primary key,
     data jsonb not null,
     updated_at timestamptz default now()
   );

   alter table family_records enable row level security;

   create policy "family room access"
     on family_records for all
     using (true) with check (true);
   ```
3. Project Settings → API에서 **Project URL**과 **anon key**를 복사합니다.
4. 앱 설정에서 방식을 `Supabase REST`, 주소에 Project URL, 키에 anon key, 가족 방 이름을 넣고 **연결하기**를 누릅니다.

### 동기화 방식과 한계

- 기록이 바뀌면 약 1초 뒤에 통째로 올리고, 8초마다 다른 기기의 기록을 확인합니다.
- 두 기기에서 동시에 고치면 `updatedAt`이 더 최신인 쪽이 남습니다. 한 사람씩 고치는 편이 안전합니다.
- 연결이 끊겨도 기록은 이 기기에 계속 저장되고, 다시 연결되면 최신 기록을 주고받습니다.
- 같은 방 이름을 아는 사람은 기록을 볼 수 있습니다. 가족 방 이름은 길고 어렵게 정하세요.

## 알아 두실 점

- **PIN 잠금은 가족 확인용입니다.** 기기 자체의 잠금이나 암호화를 대신하지 않습니다.
  브라우저 저장소를 직접 열면 내용을 볼 수 있으니, 민감한 개인정보는 적지 마세요.
- **저금통 금액은 약속 기록입니다.** 실제 결제·송금 기능이 없습니다.
- **공유 링크는 기록 전체를 담습니다.** 링크가 길어 일부 메신저에서 잘릴 수 있으니, 그때는 공유 코드를 복사해 전하세요.
- 날씨는 [Open-Meteo](https://open-meteo.com)의 무료 API를 씁니다. 상업적 사용 조건은 Open-Meteo 약관을 확인하세요.
- 캐릭터 그림은 이 앱을 위해 직접 그린 SVG라 저작권 문제가 없습니다.
